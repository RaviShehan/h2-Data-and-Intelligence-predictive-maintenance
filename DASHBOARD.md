# H3 Predictive Maintenance Dashboard

This document explains the H3 dashboard component of the Group H Predictive Maintenance System.

## Purpose of H3

H3 provides a visual dashboard for monitoring machine health predictions generated by the H2 Data Intelligence API.

The dashboard helps users view:

* latest prediction records
* machine risk levels
* anomaly status
* model information
* model evaluation report
* feature importance values

## Technology Used

The dashboard is built using:

* Python
* Streamlit
* pandas
* requests
* FastAPI endpoints from H2

## Dashboard File

The main dashboard file is:

```text
dashboard/app.py
```

## API Used by Dashboard

The dashboard reads data from the H2 FastAPI backend.

Base API URL:

```text
http://127.0.0.1:8000
```

Endpoints used:

* `GET /`
* `GET /predictions`
* `GET /model-info`
* `GET /model-evaluation`
* `GET /feature-importance`

## Dashboard Tabs

### 1. Prediction History

Shows latest prediction records stored in PostgreSQL.

Displayed fields include:

* machine_id
* temperature
* vibration_total
* rpm
* risk_level
* failure_probability
* recommended_action
* is_anomaly
* created_at

### 2. Risk Summary

Shows summary metrics for machine risk levels.

It displays:

* total predictions
* CRITICAL count
* WARNING count
* NORMAL count
* risk level bar chart
* anomaly count chart

### 3. Model Information

Shows model metadata from H2.

It displays:

* model type
* model accuracy
* model availability
* dataset source
* input features
* risk classes
* full model metadata JSON

### 4. Feature Importance

Shows feature importance values from the trained RandomForestClassifier model.

This helps explain which vibration and SciPy signal-processing features affect prediction most.

## How to Run Dashboard

First start FastAPI:

```bash
venv\Scripts\python.exe -m uvicorn api.main:app --reload
```

Then run the dashboard:

```bash
venv\Scripts\python.exe -m streamlit run dashboard/app.py
```

Open the dashboard in browser:

```text
http://localhost:8501
```
